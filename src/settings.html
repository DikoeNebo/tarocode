Phone remote

Opt-in web remote for Cursor chats on the same Wi‑Fi. Anyone on that network with the link can use it — keep the secret private.

  1. 1. Enable the switch above
  2. 2. Put the phone on the same Wi‑Fi as this PC
  3. 3. Open the QR / URL on the phone

QR uses your PC’s Wi‑Fi address. Secret stays in the link fragment. If the phone cannot open it, allow Keycode through Windows Firewall (private network).
