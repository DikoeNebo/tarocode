# Localization

UI + bundled decks ship in 10 locales: `en`, `ru`, `uk`, `de`, `es`, `fr`, `pt-BR`, `zh-CN`, `ja`, `pl`.

## Settings

| Key | Default | Meaning |
|-----|---------|---------|
| `uiLocale` | `"system"` | OS locale via `app.getLocale()`; unknown → `en` |
| `arcanaLocale` | `"en"` | Rider–Waite titles; `"ui"` follows UI language; or a locale code |

Changing `uiLocale` applies immediately to all windows and rewrites stock decks `lazy-v1` / `pro-v1` from `data/locales/{locale}/`. User-created decks are not touched.

## Files

- `electron/i18n.js` — resolve locale, `t()`, load packs (main process)
- `src/i18n.js` — renderer helper (`t`, `applyDom`, tarot names)
- `src/i18n/ui/{locale}.json` — UI strings
- `src/i18n/tarot/{locale}.json` — arcana + group names
- `data/locales/{locale}/lazy-v1.json`, `pro-v1.json` — bundled decks

## Markup

- `data-i18n="key"` → `textContent`
- `data-i18n-title`, `data-i18n-aria`, `data-i18n-placeholder`, `data-i18n-html`

Interpolation: `t("toast.hotkeyBusy", { keys: "F9" })` replaces `{keys}` in the string.
