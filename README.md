# Keycode — Lazy Coder

Прозрачная колода из **до 8 карточек-промптов** поверх всех окон. Клик или **F1–F8** вставляет текст в отмеченные чаты (Cursor, ChatGPT, Grok…).

## Запуск

Двойной клик по **`start.bat`** (или `npm start` в терминале).

При первом запуске bat сам установит зависимости. Изменения в коде видны сразу — пересборка не нужна.

**Exe для раздачи (в конце проекта):** `npm run build` → `dist\Keycode.exe`

- Подведите курсор **к краю** — карты плавно выедут  
- **F9** — закрепить / скрыть  
- **⚙** на полоске — цели и настройки  
- **▲◀▶▼** — какой край  
- Карты **в 1 ряд у края** (2-й — только если не влезает)  
- Прозрачность **80%**, заголовок карты **100%** (настраивается)  
- **⊕ цель** — прицел по окну чата

## Возможности

- Маленькие карты с реальными изображениями таро  
- Несколько целей сразу  
- Enter после вставки — вкл/выкл  
- Экспорт / импорт колоды (JSON)
